# 있니 (Inni)

결제 직전에 **집에 비슷한 옷이 있는지** 보는 체크리스트. 디지털 옷장이 아닙니다.

옷을 사기 전에 후보를 적고, 같은 카테고리·색의 보유가 있으면 “집에 있니?”를 보여 줍니다. 샀다 / 안 샀다를 남깁니다.

**데모:** _(Vercel 배포 후 URL)_  
**저장소:** _(GitHub Public URL)_

---

## 지금 버전

스프린트 미션 6 MVP. 프론트만. 서버·DB 없음. 데이터는 이 브라우저 `localStorage`에만 남습니다.

| 됨 | 안 함 |
|----|--------|
| 로컬 회원가입·로그인 | 실제 인증, 소셜 로그인 |
| 비로그인 `/` 랜딩 2시안 (1시안은 `/v1`) | 옷장 사진 카탈로그 |
| 살까 후보, 보유 한 줄 | AI 코디, 쇼핑몰 연동 |
| 카테고리+색 겹침. 기타는 직접 입력한 종류·색 이름까지 | 기기 간 동기화 |
| 샀다 / 안 샀다 | 결제·구독 UI |

로그인 화면에도 고지합니다. **실습용이에요. 서버는 없습니다.** 비밀번호는 해시하지 않고 브라우저에 저장됩니다. 실제 쓰는 비밀번호를 넣지 마세요.

---

## 로컬 실행

필요: Node.js 18+

```bash
npm install
npm run dev
```

브라우저에서 개발 서버 주소를 엽니다. PC에서도 가운데 **390px** 모바일 셸만 보입니다.

```
VITE_APP_NAME=있니
```

비밀키는 없습니다. `.env`에 계정·토큰을 넣지 않습니다.

## 잠깐 써 보기

1. 비로그인 `/`에서 랜딩을 본다. CTA로 가입한다
2. 살까 싶은 옷 이름·카테고리·색을 넣는다. 기타면 종류(또는 색 이름)를 적는다
3. 상세에서 “집에 이런 거 있음”을 한 줄 적는다
4. 겹치면 안 샀다, 없으면 샀다

온보딩에서 옷장을 채우지 않습니다. 지금 고민하는 옷 1개면 됩니다.

## 스택

React, Vite, React Router, Tailwind CSS, shadcn/ui. 전역 상태 라이브러리 없음. 배포는 Vercel.

화면은 데이터를 직접 저장하지 않고 `hooks` → `lib/auth.js` `lib/storage.js` `lib/match.js`만 부릅니다.
